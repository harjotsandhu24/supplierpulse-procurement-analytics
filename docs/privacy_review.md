# Privacy review of publishable files

Generated by `python scripts/privacy_review.py`. Counts and file names only; private values are never written here.

## Design

- **Allowlist, not redaction.** The public snapshot keeps only these columns: `SOURCE_ROW`, `PURCHASE_ORDER`, `AWARD_DATE`, `VENDOR_ID`, `VENDOR_COUNTRY`, `COMMODITY`, `QUANTITY`, `UNIT_OF_MEASURE`, `UNIT_PRICE`, `ITM_TOT_AM`, `HAS_MASTER_AGREEMENT`, `ITEM_TEXT_KEY`, `RAW_EXACT_DUPLICATE`, `DATA_BUILD_DATE`.
- **Not published:** `COMMODITY_DESCRIPTION`, `EXTENDED_DESCRIPTION`, `UNIT_OF_MEAS_DESC`, `MASTER_AGREEMENT`, `CONTRACT_NAME`, `VENDOR_CODE`, `LGL_NM`, `AD_LN_1`, `AD_LN_2`, `CITY`, `ST`, `ZIP`.
- **Vendor names:** published only for the 170 business names on `config/reviewed_vendor_names.csv`; two vendors that appear to be individuals are withheld (`config/withheld_vendor_ids.csv`); all others appear as pseudonymous IDs.
- **Item descriptions:** published only as reviewer-cleaned labels for the 153 product specifications on `config/reviewed_item_texts.csv`. Unreviewed text is not published, not even as a hash.
